# 👁️ Python Terminal Animation

سكربت بسيط بلغة بايثون لإنشاء تأثير بصري مميز داخل شاشة الأوامر (Terminal).

## 🛠️ المتطلبات (Requirements)
يجب تثبيت مكتبة `numpy` قبل التشغيل عن طريق كتابة الأمر التالي:
`pip install numpy`

## 💻 طريقة التشغيل (How to run)
1. قم بتحميل الملف `eye.py`.
2. افتح الـ Terminal في نفس مسار الملف.
3. قم بتشغيل الكود باستخدام الأمر:
`python eye.py`
